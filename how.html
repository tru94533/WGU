App Usage Instructions The application focuses on creating a simple vacation list and adding excursions to those vacations.

The Always Wonderful app is your personalized tool for travel planning. It simplifies your journey by allowing you to easily maintain a simple vacation list and organize every detail by letting you seamlessly add excursions to those vacations.

Part 1: Starting the App and creating a user profile

On the Main Activity screen, which displays the message "Always Wonderful".

Click the "Start Planning" button.

The application will navigate to the User List screen. This screen is initially blank until a user profile has been created.

To create a profile, simply enter a user name, and password. Clicking Create User to save the profile.

Part 2: Adding a New Vacation

Once the logged in, the application will navigate to the Vaction List screen which will be empty at first.

Once on the Vacation List screen, click the "+" floating button located at the bottom right corner to add a new vacation entry

The app navigates to the (empty) Vacation Details screen.Enter the required vacation information (e.g., title, hotel, start date, end date).

Note: The app includes validation to prevent the user from entering chronologically incorrect or wrongly formatted start and end dates.

To Save the vacation, Clicks the kebab menu (three vertical dots) and selects "Save Vacation"

The app navigates back to the Vacation List screen, which is now refreshed and displays the newly added vacation.

As more vacations are added, it may be beneficial to use the search feature at the top.

Part 3: Adding an Excursion to a Vacation

Clicks on the newly added vacation (or any existing vacation) from the Vacation List.

The app will navigate to the Vacation Details screen, which displays the saved information for the selected vacation.

Clicks the "+" floating button on the Vacation Details screen to add a new excursion.

The app will navigate an (empty) Excursion Details screen. Enters the excursion title, price, and date.

Note: The excursion Date is validated to ensure it falls within the associated vacation's start and end dates.

To save the excursion: Clicks the kebab menu and selects "Save Excursion"

The app will navigate back to the Vacation Details screen, which is refreshed to show the newly added excursion listed beneath the vacation details.

Additional Features (Menu Options)

From the Vacation Details and Excursion Details screens, the kebab menu offers the following functions:

Screen Menu Option Action / Description
Vacation Details Save Vacation Saves the vacation to the database table.
Delete Vacation Removes the vacation from the database table, **but only as long as there are no excursions associated with the vacation.**
Share Vacation Allows sharing of the vacation information (text or Bluetooth).
Excursion Details Save Excursion Saves the excursion to the database.
Delete Excursion Removes the excursion from the database.
Both Screens Notify Sets an alert to notify the user when the vacation has started and ended (Vacation Screen) or when the excursion date arrives (Excursion Screen).
